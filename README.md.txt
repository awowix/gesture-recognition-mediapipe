# hand gesture recognition

A Python project that uses a webcam to recognize hand gestures in real time.It can detect 7 different gestures and save the camera recording to a video file.

## gestures

the program recognizes these gestures:

- Thumb Up
- Thumb Down
- Scissors
- Paper
- Rock
- Pointing Up
- Rock On

## technologies

- Python 3.10+
- MediaPipe 0.10.21
- OpenCV 4.10.0
- NumPy 1.26.4

## how to run

Clone the repository:

```bash
git clone https://github.com/awowix/gesture-recognition-mediapipe.git
```

the webcam is required to use the application
